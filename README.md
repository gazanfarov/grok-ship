# Grok Ship

An installer pack that turns a Grok Bot workspace into a small software factory: one Firstmate agent the user talks to, per-project crewmates that drive Cursor cloud agents, an adversarial review gate before any pull request, and a local sqlite backlog.

## Install

Get this pack onto your Grok Bot's shared computer, then tell any bot: follow `GROK_SHIP.md`. The installer does the rest and hands you over to Firstmate.

## What's in the pack

- `GROK_SHIP.md` - the installer
- `GROK_BOT_FIRSTMATE.md` - the Firstmate charter
- `GROK_BOT_CREWMATE.md` - the per-project crewmate charter template
- `skills/` - three global workflows: lavish-session, adversarial-review, project-management
